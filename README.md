# Pebble WhatsApp Client

A lightweight, two-way WhatsApp client for Pebble smartwatches. Read messages, send replies, and manage your chats directly from your wrist!

## ✨ Features

* **Live Chat List:** View recent chats with unread badges and media preview tags.
* **Full Chat History:** Scroll through messages with dynamic loading ("Load older messages...").
* **Two-Way Messaging:** Reply instantly using customizable canned responses or Pebble's built-in voice dictation.
* **Action Menu:** Long-press any message to unlock advanced features:
  * **React:** Send emoji reactions (👍, ❤️, 😂, 😮, 😢, 🙏).
  * **Quote Reply:** Reply directly to a specific message in the thread.
  * **Delete:** Delete your own messages (deletes for everyone).
* **Dynamic Theming:** Full support for Light and Dark modes with automatic text contrast.
* **Read Receipts:** Visual indicators (single/double checks) for sent, delivered, and read statuses.
